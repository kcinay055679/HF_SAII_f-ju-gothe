# Tag 08 · 30.10.2026 · Projektstart

Source: the "Projektauftrag" part of `docs/General/SAII_Tag9_final.pdf`, repeated there for anyone who was absent. There are no separate Tag 8 slides in `docs/`.

## Ziel

Start the customer project: form the team, plan the architecture as a network plan and a data flow plan, and plan the work packages plus Git setup.

## Aufträge

1. **Gruppenbildung**: send the team name, class and members to the lecturer via Teams.
2. **Netzwerkplan und Datenflussplan** (45 min): architecture for Kali, LM1, Git/registry and LM2. Must show:
   - systems involved
   - communication directions
   - interfaces and ports
   - where code, images and configuration live
   - the path from commit to alert
   - open assumptions
   - application, monitoring and Mattermost marked
   - the data flow plan also shows login, stamping and access
3. **GIT aufbauen + Kurzplanung Arbeitspakete**: a short sequence of work steps, and set up Git.
